# Review and evaluation implementation

Date: 19 October 2026. Goal: build the local human review/evaluation path while real clips are unavailable. Constraints: no paid APIs, model inference for review, GPU rentals, deployment, or publication. Originals and reviewed revisions must remain separate.

Acceptance: initialize a private source-bound review; collect explicit source and atomic-claim judgments; reject missing labels and omitted text; validate a corrected target without editing original evidence; finalize a new immutable revision; aggregate counts/macro/micro/N/A without mixing source cohorts or corrections; retain rejected and missing-first-pass cases in the selected review set.

Implemented commands: `review-init`, `review-finalize`, and `evaluate`. A self-contained offline HTML page provides source-video/frame/evidence inspection, claim labels and span splitting, reference facts/conflicts/gaps, corrections, annotation download, and resume. New pipeline records hash the actual input video and preserve input classification even on failed runs. Finalized bundles copy their assets and verify manifest hashes. See [usage and limits](../11-review-evaluation.md).

Verification: 125 tests passed with no skips, including synthetic workflow fixtures, missing first passes, unsupported edits, original-file/asset drift, Unicode offsets, repeated text and technical punctuation coverage, cohort-separated macro/micro metrics, source replay deduplication, malformed-reference counts, CSV formula controls, and inert HTML payloads. Invalid/empty/nonstring citation IDs remain visible and count as unsupported instead of dropping their denominator. Page interaction handlers were tested with a network-free Node DOM simulation, including splitting, editing, downloading, and resuming. Script syntax and inline CSP hash checks passed. The browser automation tool rejected `file://` by policy; no browser-policy workaround was attempted. Visual layout, actual media playback, and browser-native download behavior remain unverified by that tool.

A pending review bundle was created from the prior full synthetic Docker attempt, including its real generated-video file and selected frame, at `outputs/review-ready`. No real human annotations or real-video quality scores were fabricated. The test suite's completed labels are explicit synthetic simulations.

The wheel built offline using the existing project build cache; it includes the review/evaluation modules and contracts and excludes private directories. The first build attempt used the empty default cache and could not resolve setuptools offline; using the existing `work/uv-cache` resolved that without downloads or dependency changes. The optional Docker image rebuilt successfully. With networking disabled, a read-only root, no capabilities, and read-only source mounts, it initialized a real synthetic-run review/video/frame bundle and correctly rejected pending finalization. Full model inference was not repeated for these review-only changes. Final implementation diff and whitespace checks passed.

Independent review found and prompted fixes for duplicated source counting, punctuation omissions, and final asset retention. Existing schema/semantic/output controls were not weakened. Natural-clip quality acceptance, a full request-denominator report, audit freeze/blinding, and study confidence intervals remain separate future work.
